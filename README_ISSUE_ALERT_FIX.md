# ANTI_FIMI 이슈 분류·확산 경보 수정

기존 D4D에 적용하는 수정본입니다. 기존 게시물과 시연 DB를 삭제하지 않습니다.

## 화면 변경

- 기본 화면은 **이슈 현황**입니다. 전선, 후퇴 명령, 동맹 충돌, 파병군, 군 시설, 민간 시설, 민간 피해, 피란, 경제, 산업 중 실제 관측된 이슈를 표시합니다.
- 각 이슈에서 **자료 연결**을 선택하면 URL·동일 문구·원본 참조에 따른 하위 자료와 원문을 볼 수 있습니다.
- 분류 근거가 없는 게시물은 **이슈 미분류 게시물**에 보존합니다. 이슈가 없어도 발생한 자료 확산 경보는 이 화면에서 열 수 있습니다.
- **원문 정보**에 실제로 일치한 어휘·분류 규칙 ID 또는 참조 원본 ID를 표시합니다.
- 질문·반박·공식 확인도 같은 주제를 다루면 같은 이슈에서 조회합니다. 같은 주장이나 허위 정보로 판정한 결과가 아닙니다.

## 경보 기준

**자료 확산 조기 주의:** 최근 24시간 중 60초 관측창에서 게시물 12개 이상, 계정 6개 이상, 원본 참조 또는 동일 자료 공유 게시물 6개 이상. 정상 속보나 반박도 해당할 수 있는 미보정 검토 기준입니다.

**반복 행동 신호:** 기존 독립 반복·여러 자료 공동 공유 기준을 유지합니다. 같은 이슈의 게시물을 합산해서 새 행동 경보를 만들지 않습니다. 조기 주의는 CIB·봇·허위성 확정이 아닙니다.

여러 이슈에 걸친 경보는 전체 원문 근거를 보여 줍니다. 전체 경보 수는 경보 ID로 중복 제거하고, 이슈별 합계에는 같은 경보·게시물이 중복될 수 있습니다. 접속 첫 조회의 기존 경보는 팝업을 만들지 않으며, 이후 새 경보가 발생하면 알림을 표시합니다.

## 실행

진행 중인 시뮬레이션이 끝난 뒤 D4D의 `veil-crawler/STOP_ANTI_FIMI.cmd`로 연결 실행을 종료하고 `START_ANTI_FIMI.cmd`를 실행합니다. 대시보드는 http://127.0.0.1:8788/ 입니다. 다른 실행 방식으로 띄운 8787 서버와 혼동하지 마세요. 파일을 교체할 때는 해당 수정 ZIP의 D4D 구조를 유지하고, 자신의 DB·운용표를 임의로 삭제하지 마세요.

## 실제 검증 결과와 한계

저장된 가상 전시 시연 1,801개 게시물: 상위 이슈 10개, 분류된 고유 게시물 1,798개, 미분류 3개, 자료 확산 조기 주의 8건, 반복 행동 신호 1건. 이 시연에서 상위 분류가 잘 정리된 결과이며 실제 데이터의 정확도·오탐률을 측정한 결과는 아닙니다.

엔진 155개 테스트, 알림 상태 11개 테스트 통과. 브라우저에서 이슈 10개 표시, 갱신 후 선택 유지, 확산 지표, 새 게시물 수신 후 조기 주의 팝업과 원문 12개 이동을 검증했습니다. 별도 읽기 전용 OpenAI 검토에서 발견한 회귀 문제를 수정했습니다.

AI를 사용하지 않습니다. 공개 본문 어휘 규칙과 유효한 원본 참조로 지정 주제를 분류하므로 새로운 표현·지원되지 않는 언어·문맥 의존 표현은 놓칠 수 있습니다. 같은 이슈의 별도 사건을 자동 구별하는 의미 군집 모델이 아닙니다. 군집 수를 무조건 10으로 맞추거나 숨은 시나리오 정답을 읽지 않습니다. 세부 판단에는 원문 검토가 필요합니다.

운용표의 40개 시나리오는 검증·대응 유형입니다. 모든 유형에 자동 탐지 규칙이 구현된 것은 아닙니다. 이슈 분류와 시나리오 검토 후보를 구분하고, 관측 근거가 있는 유형에만 대응 순서를 연결해야 합니다.
