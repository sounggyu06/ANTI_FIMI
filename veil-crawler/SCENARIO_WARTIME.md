# 전시 복합 위기 시나리오

등장국은 중앙아시아연합국·북공화국·남공화국·남태평양국 네 곳이다. 남공화국과 북공화국은 전쟁 중이며 남공화국–남태평양국은 동맹이다. 지원 분담과 보급 조율의 이견으로 동맹 협력이 악화됐으나 동맹 해체나 동맹군 간 교전은 확정되지 않았다. 중앙아시아연합국은 북공화국에 비공개 무기 지원을 하는 배후 지원국이다. 공개 피드에는 이 지원이 의혹으로 등장하고 평가용 기준 자료에서만 지원 사실이 확정된다. 구체적인 무기 이동 경로나 지원 실행 절차는 설정하지 않는다.

일부 전선과 시설에 피해가 있으며 물류·피란·구호 부담도 증가하고 있다. 시뮬레이션에서는 이 제한된 사실과 전국적 붕괴를 주장하는 허위 정보가 동시에 관측된다. 질문, 반박과 공식 확인도 같은 피드에 등장한다. 네 국가명은 이 가상 세계 내부의 명칭이며 실제 사건을 뜻하지 않는다.

앞서 정한 열 가지 이슈는 모두 유지한다. 전선 패배, 항복·후퇴 명령, 동맹 충돌, 파병군 철수, 군 시설 파괴, 민간 시설 파괴, 민간 피해 급증, 피란민 급증, 경제 붕괴, 산업시설 붕괴가 같은 사건 시간대에 겹쳐 관측된다. 네 국가의 전쟁·지원·동맹 관계는 이 열 가지 이슈의 배경이며, 기존 이슈를 대체하지 않는다. 시설 전체 파괴나 전군 항복 같은 확대 주장은 기준 사실과 구분해 평가한다.

화면 상단에서 연구용 시뮬레이션임을 표시한다. 게시물 본문에는 훈련 접두어, 자료 번호, 예시 URL을 넣지 않는다. 실제 국가·인물·부대·시설·피해자의 정보를 사용하지 않는다. 음성 합성·명령 위조는 검증 대상 유형으로만 설정하고 실제 음성 자산이나 실행 가능한 명령은 만들지 않는다.

| 이슈 | 훈련의 기준 사실 | 반증할 주장 |
|---|---|---|
| 전선 상황 | 일부 후퇴, 다른 구역 방어 유지 | 모든 전선 붕괴 |
| 후퇴 명령 | 일부 구역 재배치, 전군 항복 명령 없음 | 군 통수권자의 전군 항복·철수 발표 |
| 동맹국 충돌 | 보급 조율·지원 분담 이견으로 협력 악화, 무력 충돌 미확인 | 동맹군 간 교전 |
| 파병군 철수 | 예정된 일부 인력 교대 | 모든 파병군 철수·지원 중단 |
| 군 시설 피해 | 보급시설 한 곳 피해, 다른 시설 확인 중 | 모든 주요 군 시설 파괴 |
| 민간 시설 피해 | 한 지역 피해, 전국 상태는 별도 확인 | 전국 병원·기반시설 붕괴 |
| 민간 피해 | 피해 발생, 집계 진행 중 | 공식 집계 수십 배로 확정·은폐 |
| 피란·구호 | 수요 증가, 일부 대피소 운영 | 모든 대피소 폐쇄·지원 중단 |
| 경제 | 물류 차질·가격 변동 | 모든 금융기관 지급 중단 |
| 산업 | 일부 가동 중단, 시설별 상태 상이 | 모든 산업시설 파괴·생산 영구 중단 |

## 실행

메인 프로젝트의 웹을 재시작하고 ‘훈련 시나리오’에서 ‘전시 복합 위기 · 10개 이슈’를 선택한다.

- 시나리오 시작: 개요 1개를 시작 시각에 기록한 뒤 주장 1,500개와 비교 글 300개를 한 개씩 게시한다.
- 게시 간격: 다음 글까지의 대기 시간을 매번 100~400밀리초 사이의 균등 난수로 정한다. 전체 1,801개 완료까지 평균 약 7분 30초의 대기 시간이 예상되며 저장·처리 지연은 추가될 수 있다.
- 작성 시각: 실제 게시 순간의 서버 현재 시각을 사용한다. 모든 새 글은 시뮬레이션 시작 시각 이후이며 ISO 8601 밀리초를 유지한다. 화면에는 KST 밀리초까지 표시한다.
- 중지: 다음 글의 생성을 중단하고 기존 글은 유지한다. 전시 시나리오의 이전 빠른·반복 API 호출도 동일한 실시간 규칙을 사용한다.
- 테스트 초기화: 이번 및 이전 가상 실행의 게시물만 정리한다. 실제 수집 게시물과 직접 작성한 글은 유지한다.

전시 시나리오에는 과거 시각을 무작위로 배정하는 시간 패턴과 15초 일괄 생성 기능을 적용하지 않는다. 타이머 처리가 지연돼도 누락된 글을 한 번에 따라잡지 않고 현재 시각에 한 개만 게시한 뒤 다음 간격을 정한다. 실제 수집 게시물과 이전에 저장된 글의 작성 시각은 변경하지 않는다. 서버 재시작 후에는 기존 방식대로 준비 상태에서 시작한다. 기존 재난구호 시나리오의 시간 패턴은 유지된다.

## 검증

같은 가상 작성자는 고정된 익명 프로필을 사용한다. 주장 1,500개는 60개 계정에 난수로 배분한다. 한 글만 쓰는 계정과 여러 글을 쓰는 계정을 함께 포함하며 난수 seed에 따라 실행마다 배분이 달라진다. 기사 형식뿐 아니라 개인 의견·소문·질문·인용 반응을 섞는다. 재게시 대상은 같은 주제의 이전 게시물에서 선택하므로 소문과 중간 재게시에도 연결된다. 작성 시각보다 미래의 글을 원문으로 연결하지 않는다.

게시물 길이도 섞는다. 약 40%는 5개의 내용 있는 줄로 작성하며, 주제별 범위·지역·시각·집계 기준 등 맥락을 덧붙인다. 나머지는 짧은 글이다. 화면 폭에 따른 자동 줄바꿈과 별도로 본문 자체에 줄바꿈이 들어 있다. 실제 목격자·유출 문서·군 지휘 명령은 만들어 넣지 않는다.

좋아요는 테스트용 합성 수치다. 일부는 0, 다수는 1~90, 일부는 120~3,999, 약 10%는 5,000~49,999 범위를 사용한다. 시뮬레이션 단계가 진행되면 수치가 증가한다. 진위·역할 라벨에 따라 인기도를 배정하지 않으며 소문·반박·공식 확인에도 높은 수치가 나타날 수 있다. 실제 SNS 계정 활동이나 좋아요 요청을 실행하지 않는다.

주장·질문·반박·공식 확인 역할과 정답은 서버 내부 자료로만 관리한다. 공개 API와 크롤러의 6필드 JSONL에는 정답을 넣지 않는다. `comment`는 댓글 여부이며 진위 라벨이 아니다.

평가용 기준 자료는 서버 코드의 `fixtures/wartime-ground-truth.json`에 있다. 모델에 정답을 직접 주입하지 않고 별도 평가에 사용한다. 공식 확인 글은 관측 가능한 증거 자료이므로 피드에 포함된다.

유형별 잠재등급은 실제 사건 등급과 다르다. 특히 Critical은 임박한 안전 위해·구체적 행동 지시·실제 대상 노출을 확인한 경우에만 검토한다. 이 텍스트 데이터만으로 실제 지휘체계 붕괴, 설득 효과, 국가 배후 또는 인명 위해가 입증되지는 않는다.
