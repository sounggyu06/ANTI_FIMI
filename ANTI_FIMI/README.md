# ANTI_FIMI

공개 게시물을 원문으로 저장하고 자료 연결과 반복 행동을 분석하는 로컬 탐지·분석가 대시보드입니다. 기본 실행은 AI·모델·API 키를 사용하지 않습니다. 외부 AI 군집 수신과 기존 임베딩은 명시적으로 선택하는 호환 모드로 보존합니다. 별도 API 키·모델 다운로드 없이 원문 수집과 행동 데모, 테스트를 실행할 수 있습니다.

## 빠른 실행

엔진에는 Python 3.10 이상이 필요합니다. Git 소스 배포본은 먼저 [최상위 실행 안내](../README.md)에 따라 Node.js로 대시보드를 빌드하세요. Windows 통합 실행은 Python 3.12를 사용합니다. 최상위 폴더에서:

```powershell
py -3.12 .\ANTI_FIMI\make_fusion_demo.py
py -3.12 .\ANTI_FIMI\server.py
```

브라우저에서 http://127.0.0.1:8787/을 엽니다. Ctrl+C로 서버를 종료합니다. `engine.py`는 하위 명령이 필요한 CLI이며, 파일만 실행하는 방식 대신 위 실행 방법을 사용하세요.

첫 명령은 명시적인 합성 게시물 49개를 별도 `ANTI_FIMI_fusion_demo.sqlite3`에 저장합니다. 예상 결과는 **원문 49개·계정 31개·계정 쌍 신호 15개·상위 조사망 1개·외부 AI 수신 0개**입니다. 반복 계정 6개가 포함되고 단발 속보 공유 20개 계정과 일반 글 5개 계정은 조사망에 포함되지 않습니다. 재실행 시 49개가 중복으로 처리되며 조사망 ID의 재시작 복원을 검증합니다. 이 결과는 실전 정확도 평가가 아닙니다.

```text
ANTI_FIMI/                     엔진·API·테스트·문서
fimi-dashboard/                React 소스·로컬에서 생성하는 dist
ANTI_FIMI_DEMO_DATA/            실행 시 생성되는 원문·DB·결과 (Git 제외)
```

기존 46개 문자 특징 데모와 DB는 보존합니다. 실행하려면 `py -3.12 .\ANTI_FIMI\make_demo.py --run`을 사용하고, 기존 화면 모드는 `server.py --local-preview --db .\ANTI_FIMI_DEMO_DATA\ANTI_FIMI_demo.sqlite3`로 명시합니다. 기존 CLI의 `export`는 그 로컬 미리보기 결과를 내보냅니다. 새 행동/Fusion 결과는 `/api/dashboard`와 SQLite의 별도 테이블에서 조회합니다.

## 화면 읽기

- **행동 조사망:** 내용 군집을 가로지르는 반복 계정 관계를 먼저 봅니다. 여러 계정 쌍의 신호를 하나의 조사망으로 묶고 자식 신호·근거 ID를 보존합니다.
- **자료 묶음:** 동일 URL, 같은 참조 원본 ID, 20자 이상 동일 문구를 UTC 날짜별로 연결합니다. 최소 게시물 2개부터 표시합니다. 의미·입장 분류가 아니며 같은 URL의 주장과 반박이 함께 나타날 수 있습니다. 묶음 간 중복 소속이 가능하므로 합산 수치를 전체 게시물 수로 사용하지 않습니다.
- **미연결 게시물:** 자료 연결이 없는 원문입니다. 행동 분석에는 계속 포함됩니다. 정상 사용자의 글을 악성 계정으로 판정하지 않습니다.
- 관계선·계정·세부 행동 신호를 선택하면 관련 원문·URL·시각·reason_codes를 확인할 수 있습니다. 화면은 3초마다 갱신하며 선택을 유지합니다.
- 기본 모드는 AI 결과를 기다리지 않습니다. 외부 AI 호환 모드에서만 군집 수신·대기 상태를 표시합니다. 입장이나 허위성을 임의 생성하지 않습니다.
- 상단은 원문·계정 수, 행동 신호, 최근 집계와 군집 결과 수신 현황만 표시합니다. 수집 시각은 `수집 정보`, 원문 ID는 `원문 정보`, 점수 구성과 해석 한계는 각각 상세 항목에서 펼칩니다. 관계가 없는 군집은 빈 그래프 대신 관계 수와 계정 선택 목록을 표시합니다.

## 파이프라인과 점수

```text
사이트 원문 → SQLite 원시 게시물 ┬→ 행동 분석 → 반복 행동 조사망
                              └→ 자료 연결 → 자료 묶음/미연결 원문
두 경로를 근거 게시물 ID로 연결 → 확산 흐름/운용표 대응 절차
```

SQLite/API가 두 경로의 접점을 제공합니다. 기본 모드는 모델을 로드하거나 호출하지 않습니다. 외부 AI 호환 모드에서는 별도 모듈이 생성한 군집만 수신합니다. 독립 워커·메시지 브로커를 운영하는 분산 시스템은 포함하지 않습니다.

행동 분석은 텍스트·임베딩·입장·시나리오 라벨을 사용하지 않습니다. 최근 24시간에서 동일 자료(URL 또는 참조 원본)에 대해 60초 이내 공동 행동을 찾아, 독립 시간대 3회 이상 및 서로 다른 자료 2종 이상을 요구합니다. 이어진 긴 버스트나 한 번에 여러 URL 공유는 독립 반복으로 부풀리지 않습니다.

시간 근접도·반복성·자료 다양성의 가중 합을 자료 인기도와 계정 활동량으로 낮추고, 실제 관측된 양방향 참조에 제한적 보조 점수를 줍니다. `network_score`는 미보정 검토 지표이며 봇/CIB 확률이 아닙니다. 단순 곱셈·기하급수 증폭으로 확신을 과장하지 않습니다. ‘외부 관계 없음’은 관측 누락일 수 있으므로 닫힌 조직망의 증거로 사용하지 않습니다.

상위 조사망은 모든 계정 쌍에 반복 행동 신호가 존재하는 핵심망으로 구성하고, 자식 신호의 최신 관측 시각 간격은 최대 1시간으로 제한합니다. 30% 겹침을 연쇄 적용해 무관한 집단까지 합치는 문제를 피하는 보수적 방식입니다. 불완전하게 관측된 같은 조직이 여러 조사망으로 나뉠 수 있습니다. 같은 핵심 계정 집합은 시간대 갱신과 재시작 후에도 조사망 ID를 유지하고, 근거 변경 이력과 비활성 신호를 DB에 보관합니다.

외부 AI 호환 모드에서 군집 결과가 도착하면 같은 원문 ID로 연결합니다. 군집별 시간 확산 이상은 완료된 시간대와 직전6시간 기준선으로 계산합니다. 군집에는 지지·반박·질문이 섞일 수 있으므로 특정 주장의 확산으로 단정하지 않습니다. 데이터 수집 누락은 0으로 관측되므로 기준선의 완전성은 미확인입니다.

## 사이트 원시 데이터 입력

필수 필드는 `id`, `account_id`, 시간대가 있는 `created_at`, `text`입니다. 사이트의 불변 ID를 사용하세요. 옵션은 `urls` 문자열 배열, `language_hint` 문자열/null, `relations` 배열/null입니다. 원본 참조는 `quotes`, `reposts`, `replies_to`와 `target_post_id`로 전달합니다.

```http
POST http://127.0.0.1:8787/api/posts
Content-Type: application/json

{"posts":[{"id":"site-001","account_id":"user-42","created_at":"2026-10-10T08:00:00Z","text":"훈련 취소 주장의 근거를 확인 중입니다.","urls":["https://example.invalid/updates/1"],"language_hint":"ko","relations":[{"type":"quotes","target_post_id":"site-original"}]}]}
```

원본 ID가 존재하지 않으면 관계선을 만들지 않고, 원문 도착 후 재평가합니다. 공동 공유는 추정 무방향선, 인용·재공유·댓글은 작성자→참조 원문 작성자의 관측 방향선입니다. 인과적 전파 방향이나 최초 유포를 확정하지 않습니다.

또는 `ANTI_FIMI_DEMO_DATA/posts/live_posts.jsonl`에 게시물 객체를 한 줄씩 추가합니다. 서버는 1초마다 완성된 줄을 읽습니다. 불완전 줄은 대기하고 잘못된 줄은 소비하지 않으며, 수정 후 재시작·파일 교체에도 중복을 제거합니다. 동일 ID의 다른 원문은 거부합니다. 수정·삭제 이벤트는 별도 계약이 필요합니다.

실시간 입력은 현재 시계로, 과거 재생은 POST 본문의 `source_now`로 분석합니다. 빈 DB의 최초 재생 시간을 존중하고 이후 시각은 역행하지 않습니다. 재생은 자동 진전하지 않습니다. 수집기 시계보다 5분 넘게 미래인 글은 거부하고 허용 범위의 미래 글은 시각이 될 때까지 행동 분석에서 기다립니다. AI 처리 대기와 행동 처리 대기는 따로 표시합니다.

실제 입력은 데모 DB와 분리하세요:

```powershell
py -3.12 .\ANTI_FIMI\server.py --db .\ANTI_FIMI_DEMO_DATA\ANTI_FIMI_live.sqlite3 --watch .\ANTI_FIMI_DEMO_DATA\posts\site_posts.jsonl
```

## 선택 호환 모드: 외부 AI와 팀원 자료

`server.py --external-ai`로 시작한 경우에만 AI 담당자는 `GET /api/ai/pending`으로 원문/해시를 받아 군집화하고 `POST /api/ai/results`로 게시물별 `cluster_id` 또는 미배정 `null`을 보냅니다. 명제·입장·GPT 요약은 요구하지 않습니다. 전체 계약은 [AI_CONTRACT.md](AI_CONTRACT.md)를 보세요. 원문 해시·revision·군집 필드를 검증하고 실패 배치는 원자적으로 거부합니다.

받는 ZIP은 `manifest.json`과 전체 원문·군집 배정을 담은 `posts.jsonl` 두 파일로 정리했습니다. 벡터·계정 분석·GPT 보고서·군집별 중복 파일은 필요하지 않습니다. 기존 전체 ZIP을 줄이고 수신하는 어댑터도 있습니다:

```powershell
py -3.12 .\ANTI_FIMI\pack_ai_bundle.py --input "기존 전체 ZIP 경로" --output .\ANTI_FIMI_DEMO_DATA\ai_inbox\ANTI_FIMI_AI_INPUT.zip
py -3.12 .\ANTI_FIMI\import_team_raw.py --input .\ANTI_FIMI_DEMO_DATA\ai_inbox\ANTI_FIMI_AI_INPUT.zip
py -3.12 .\ANTI_FIMI\server.py --db .\ANTI_FIMI_DEMO_DATA\ANTI_FIMI_team_bundle.sqlite3 --no-watch
```

이미 정리된 ZIP은 두 번째 명령부터 사용하세요. 기존 전체 ZIP도 계속 수신할 수 있습니다. 정리 도구는 원본을 보존하고 게시물 ID·원문을 바꾸지 않으며 오류가 있거나 군집화가 미완료인 실행은 거부합니다. 세부 전달 규격은 [AI_CONTRACT.md](AI_CONTRACT.md)에 있습니다.

해당 자료 116개는 별도 DB에서 실행했고, 현재 강한 반복 행동 신호 0개입니다. 실제 군집 배정87개와 미배정29개를 수신하여17개 내용 군집을 연결했습니다. 과거 GPT 참고본은 보관하지만 새 입력에는 요구하지 않습니다. 역할을 stance로 바꾸지 않으며 입장·허위성은 미분석으로 표시합니다. 자세한 분석은 [AI_BUNDLE_REVIEW.md](AI_BUNDLE_REVIEW.md)에 있습니다.

## 입력 파일을 직접 분석

아래는 `ANTI_FIMI` 폴더에서 실행합니다. 기본 데모와 별도의 DB·출력 경로를 사용합니다.

```powershell
py -3.12 engine.py --db ../ANTI_FIMI_DEMO_DATA/ANTI_FIMI_manual.sqlite3 --embedder lexical-demo ingest --input ../ANTI_FIMI_DEMO_DATA/posts/demo_posts.jsonl --out ../ANTI_FIMI_DEMO_DATA/results/manual --as-of 2026-10-01T08:00:00Z
```

JSONL은 한 줄당 `id`, `account_id`, 시간대가 있는 `created_at`, `text`를 가진 객체입니다. `urls`는 선택 문자열 배열입니다. 실제 API의 원시 필드가 다르면 `veil_mapping.example.json`과 수집 어댑터를 실제 응답에 맞춰야 합니다.

## 실제 다국어 의미 모델 — 선택 설치

현재 기본 데모 실행을 위해 설치할 필요는 없습니다. 아래는 CPU 의미 모델 실행 환경을 새로 만드는 예시이며 최초 설치에는 인터넷과 모델 다운로드가 필요합니다. 모델 가중치·가상환경은 이 배치에 포함하지 않았습니다.

```powershell
cd .\ANTI_FIMI
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch==2.8.0 --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe tests/semantic_smoke.py
.\.venv\Scripts\python.exe make_demo.py --run --embedder semantic --db ../ANTI_FIMI_DEMO_DATA/ANTI_FIMI_semantic.sqlite3 --results ../ANTI_FIMI_DEMO_DATA/results/semantic
```

실제 의미 모델과 기본 문자 데모는 서로 다른 DB를 사용해야 합니다. 모델/config가 다르면 엔진은 같은 DB 사용을 거부합니다. 의미 모델 스모크 확인 결과도 기본적으로 더미 폴더의 `results/semantic_smoke.json`에 저장됩니다.

| events.py | 기존 자체 임베딩의 잠정 사건 묶음 |
| tests/ | 실행 가능한 단위·API·회귀 테스트 |

현재는 해커톤 규모의 재계산 방식입니다. 인기 자료의 계정 쌍 생성 비용, 긴 이력 조회와 이력 저장량이 커지므로 대량 실시간 운영에는 증분 처리·보존 정책이 필요합니다. 반복적인 정상 협업은 오탐 후보이며, 저속·단일 자료·단발 캠페인은 강한 반복 조건에서 누락될 수 있습니다. 현재 테스트는 설계된 동작을 확인하며 실전 성능을 보장하지 않습니다.

서버는 127.0.0.1에만 열리고 인증·공개 배포 운영은 포함하지 않습니다. 팔로워 관계·미디어가 수집되지 않으면 해당 분석은 하지 않습니다. 딥페이크 판별·국가 배후 귀속·외부 사실 검증·자동 대응은 구현되지 않았습니다. 실제 AI 결과나 시나리오 정답, 계정 이름을 악성 라벨로 만들지 않습니다.
# Excel 운용표와 대응 절차

`D4D/ANTI_FIMI_운용표_v1.0.xlsx`가 실제 운용 기준입니다. 서버 시작·게시물 수신·AI 군집 수신·재분석 시 읽습니다. 다른 경로는 `server.py --playbook "경로.xlsx"`로 지정합니다. Excel 저장 후 대시보드의 **운용표 재읽기** 또는 `POST /api/playbook/reload`에 `{}`를 보내면 기존 분석 시점에서 재평가합니다. 새 게시물을 기다릴 필요가 없습니다.

- `운용목록`: 유형 ID, 검증 과제, 참고 잠재등급.
- `대응절차`: ID별 순서, 담당, 착수 조건, 수행할 일, 산출물, 완료 확인, 권한 경계. 행 위치보다 `순서` 값으로 정렬합니다. ID는 `01`처럼 두 자리 텍스트, 순서는 중복·누락 없는 1부터의 정수입니다.
- `매칭규칙`: 초기 자동 후보 규칙 3개. `enabled`는 TRUE/FALSE, 조건 목록은 JSON 문자열 배열입니다. `coordination`, `multilingual`, `topic_change`만 지원하며 다른 종류는 코드 구현이 필요합니다. 기존 6개 시트의 운용 내용은 보존하고 연결 상태 1셀만 갱신했습니다.

| 유형 | 자동 후보 연결 조건 | 해석 경계 |
|---|---|---|
| 17 반복 공동 확산 | 하나의 행동 신호에서 독립 반복 3회 이상·자료 2개 이상·지정 reason_codes 모두 충족 | 정상 협업 가능. 조직·봇·의도 미확인 |
| 22 다국어 확산 | 같은 외부 AI 의미 군집에서 보고된 언어 태그 2개 이상 | 같은 명제·입장·서사 세탁의 확인 아님 |
| 30 행사 취소·일정 조작 | 같은 게시물 안에서 훈련/행사와 취소/변경 표현 동시 언급 | 반박·질문도 후보. 사실 여부는 공식 일정과 원문으로 확인 |

40개 유형의 대응 절차를 읽지만 자동 매칭은 위 3개만 지원합니다. 나머지 유형은 자동으로 판단하지 않습니다. 언론사 위장에는 공식 도메인 대조, 딥페이크에는 미디어 검증 등 추가 증거와 별도 탐지 기능이 필요합니다. 운용표의 `위험조건`은 보존하되, 현재 자동 후보에는 검증된 사실 입력이 없어 사건 위험도를 `UNASSESSED`로 둡니다. 유형의 잠재등급을 사건 위험도로 복사하지 않습니다. 신고·게시·차단 등 외부 조치는 실행하지 않습니다.

Excel의 반복 조건은 **기존 행동 탐지기가 생성한 신호에 대한 추가 필터**입니다. `min_episodes=2`로 내려도 행동 탐지기의 기본 독립 반복 3회 조건을 완화하지 않습니다. 다국어 판단에는 원자료의 `language_hint`, `language`, `lang`만 사용합니다. 태그가 없거나 불명확하면 추측하지 않습니다. `en-US`/`en-GB` 같은 변형은 `en`으로 통합합니다. 원문 키워드는 의미 분석이 아니므로 표현 변형과 미지원 언어를 놓칠 수 있습니다.

후보는 자료 묶음·행동 조사망의 **대응 절차**에서 확인하며 미연결 원문에도 표시됩니다. 외부 AI 호환 모드에서는 AI 군집·미배정·대기에도 연결됩니다. 각 후보에 근거 게시물 ID, 규칙, 관측값, 적용 Excel SHA-256 및 당시 순서가 저장됩니다. `playbook_versions`에는 해시별 운용표 파싱 결과, `playbook_history`에는 변경·비활성 이력이 남습니다. 과거 문구를 현재 Excel로 다시 조립하지 않습니다.

파일 누락·손상·잘못된 ID/순서/조건·수식 셀은 명시적인 **운용표 적용 중지** 상태가 되며 기존 후보를 비활성화합니다. 원시 수집과 행동 분석은 계속됩니다. 오류를 수정하고 재읽기하면 후보를 다시 생성합니다. 수식·매크로·임의 Python 표현식은 실행하지 않습니다. 운용표를 바꾸어도 공식 DISARM/EEAS/NATO의 인증이나 확정 판정이 되는 것은 아닙니다.

검증: 프로젝트 폴더에서 `py -3.12 -m unittest discover -s tests -p "test_*.py"`.


## 검정 테마·실시간 알림·확산 표시

기본 화면은 검정 배경과 회색 카드입니다. 신규 경보와 검토 우선순위 상승은 상단 알림과 8초 팝업으로 표시합니다. 첫 조회의 기존 경보는 알리지 않습니다. 동일 행동 신호는 시간대 ID가 바뀌어도 중복 알림을 억제합니다. 알림을 선택하면 현재 사건과 근거로 이동하며, 유입만으로 분석가의 선택을 바꾸지 않습니다. 접속 이후 최근 30건을 보관하고 브라우저 새로고침 시 초기화됩니다.

확산은 최근 5분과 직전 5분의 관측 게시물·고유 계정을 비교합니다. 자료 축적 중 / 관측 소량 / 유지 / 가속 / 급증 / 둔화로 표시하고 최근 15분 선 그래프와 상위5개 비교 막대를 제공합니다. 막대는 참여 계정의 상대 규모이며 위험도나 공작 확률이 아닙니다. 기존 검토 등급을 먼저 정렬합니다.

최소 이력10분을 요구합니다. 이전5개 이상에서 30% 이상·3개 이상 감소하면 둔화, 현재5개 미만 또는 계정3개 미만이면 소량, 현재8개 이상·직전의2배 이상이면 급증, 30% 이상·3개 이상 증가하면 가속입니다. 증가 판단에는 고유 계정 수가 줄지 않아야 합니다. 나머지는 유지입니다. 자체 규칙이며 실전 보정값이 아닙니다. 최초 게시 시각은 수집 연속성을 증명하지 않습니다.

실시간 입력은 새 게시물이 없어도 시간이 지나면 확산 구간을 이동합니다. `source_now`를 보낸 재생 입력은 명시된 자료 시각에 고정합니다. 중지·오류 상태를 화면에 표시합니다. OS의 모션 감소 설정을 존중합니다.

## AI 없는 기본 모드

기존 팀원 DB로 실행하는 예:

```powershell
py -3.12 .\ANTI_FIMI\server.py --db .\ANTI_FIMI_DEMO_DATA\ANTI_FIMI_team_bundle.sqlite3 --no-watch
```

`--no-watch`를 빼면 기본 JSONL 파일 수집을 재개합니다. 화면 자동 갱신과 파일 감시는 별도입니다. 외부 AI를 다시 연결할 때만 `--external-ai`를 추가합니다. 기존 AI 결과와 원문은 삭제하지 않습니다. 기본 모드의 AI 수신 API는 명시적으로 거절하고 AI 대기 목록은 빈 상태를 반환합니다.

자료 ID는 `SHARED_URL`, `SHARED_REFERENCE`, `EXACT_TEXT`와 자료 값·UTC 날짜를 해시해 재시작과 입력 순서에 동일하게 유지합니다. URL의 의미 있는 쿼리는 보존하고 추적 파라미터만 기존 정규화 기준으로 제거합니다. 링크 목적지를 방문하거나 단축 URL을 해제하지 않습니다. 원문 참조는 작성 시점 이전24시간 내 관측 원문만 묶음에 포함합니다. 관측되지 않은 원문의 작성자·내용은 생성하지 않습니다. 참조 원본을 공유한 게시물끼리의 묶음은 만들 수 있습니다.

날짜 경계에서 같은 자료가 분리되고, URL이 다른 번역·의역은 연결하지 못합니다. 같은 문구만으로 경보를 만들지 않습니다. 중복 묶음을 계정 공유만으로 연쇄 병합하지 않습니다. 여러 플랫폼을 받으면 `id`, `account_id`, `target_post_id`에 플랫폼 접두어를 포함한 전역 고유 ID를 공급해야 합니다. 입력 계약은 플랫폼별 숫자 ID 충돌을 자동 해결하지 않습니다.

운용표 유형17 행동 반복과 유형30 원문 키워드 후보는 계속 연결합니다. 다국어 의미 군집이 필요한 유형22 자동 연결은 중지하며 화면에 표시합니다. Excel 원본과 과거 AI 결과는 보존합니다. 확정 위험도·허위성·입장·배후 귀속을 자동 판정하지 않습니다.
